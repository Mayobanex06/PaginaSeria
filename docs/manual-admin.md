# Manual de administrador

Este manual explica el uso basico del panel administrativo.

## 1. Acceso al panel administrativo

El administrador debe iniciar sesion con una cuenta que tenga rol `Admin`.

Si un usuario normal intenta acceder al panel, el sistema debe bloquear el acceso o redirigirlo.

## 2. Panel principal

El panel administrativo permite gestionar informacion interna del sistema.

Secciones principales:

- Productos.
- Usuarios.
- Ventas, si se implementa en el futuro.
- Reportes, si se implementa en el futuro.

## 3. Gestion de productos

Desde la seccion de productos, el administrador puede consultar los productos registrados.

Acciones posibles:

- Ver productos.
- Agregar producto.
- Editar producto.
- Inactivar o eliminar producto.

Datos importantes del producto:

- Nombre.
- Marca.
- Descripcion.
- Precio.
- Stock.
- Imagen.
- Categoria.
- Estado.

## 4. Gestion de usuarios

Desde la seccion de usuarios, el administrador puede consultar usuarios registrados.

Acciones posibles:

- Ver usuarios.
- Agregar usuario, si el sistema lo permite.
- Editar informacion de usuario.
- Inactivar usuario.

Datos importantes del usuario:

- Nombre.
- Correo.
- Rol.
- Estado.
- Ultimo inicio de sesion.

## 5. Recomendaciones para administradores

- Verificar los datos antes de editar productos.
- No eliminar informacion importante sin revisar.
- Mantener actualizado el stock.
- No compartir cuentas administrativas.
- Usar cuentas separadas para usuarios normales y administradores.

## 6. Riesgos administrativos

- Editar mal el stock puede afectar la experiencia del cliente.
- Cambiar roles sin control puede crear problemas de seguridad.
- Inactivar productos equivocados puede ocultarlos de la tienda.
- No validar datos puede causar errores en el sistema.
