# Refactorización de arquitectura base

## Objetivo

Reducir repetición de código, separar responsabilidades y preparar el proyecto para escalar ventas, carrito, usuarios, direcciones y pagos.

## Regla principal

No agregar nuevas funcionalidades hasta terminar la refactorización base.

## Prioridad

1. Frontend API reutilizable
2. Admin modular
3. Backend por capas
4. Validadores reutilizables
5. Respuestas estándar
