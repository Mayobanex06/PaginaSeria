# Manual de usuario

Este manual explica el uso basico del sistema desde la perspectiva de un cliente.

## 1. Acceso al sistema

El usuario puede acceder al sistema desde la pagina principal de CoreTech. Desde ahi puede navegar hacia la tienda, revisar productos y acceder a las opciones de cuenta.

## 2. Registro de usuario

Para crear una cuenta, el usuario debe entrar a la pagina de registro y completar el formulario correspondiente.

Datos solicitados normalmente:

- Nombre.
- Correo electronico.
- Contraseña.

Despues de completar el formulario, el sistema valida la informacion y crea la cuenta si los datos son correctos.

## 3. Inicio de sesion

Para iniciar sesion, el usuario debe ingresar su correo electronico y contraseña.

Si los datos son correctos, el sistema activa la sesion y permite acceder a funciones privadas, como el carrito de compras.

## 4. Consulta de productos

Desde la tienda, el usuario puede revisar los productos disponibles. Cada producto puede mostrar informacion como:

- Nombre.
- Marca.
- Precio.
- Imagen.
- Stock.
- Categoria.

## 5. Uso del carrito

El usuario puede agregar productos al carrito desde la tienda.

Dentro del carrito puede:

- Ver productos agregados.
- Aumentar cantidad.
- Disminuir cantidad.
- Eliminar productos.
- Consultar subtotal, envio y total, si esas funciones estan implementadas.

## 6. Cierre de sesion

El usuario puede cerrar sesion desde el menu de usuario o desde la opcion correspondiente en la interfaz.

Al cerrar sesion, el sistema elimina la sesion activa y restringe nuevamente el acceso a funciones privadas.

## Recomendaciones para el usuario

- Verificar los datos antes de registrarse.
- No compartir la contraseña.
- Revisar el carrito antes de continuar con una compra.
- Cerrar sesion si se usa un equipo compartido.
