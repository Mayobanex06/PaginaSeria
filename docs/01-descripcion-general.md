# Descripcion general del proyecto

CoreTech es una plataforma web de comercio electronico enfocada en la venta de celulares. El sistema permite que los usuarios visualicen productos disponibles, consulten información básica como nombre, marca, precio, imagen, categoria y stock, y puedan agregar productos al carrito de compras.

El proyecto tambien incluye un sistema de autenticacion para usuarios, manejo de sesiones mediante cookies y un panel administrativo. Desde ese panel, los usuarios con rol de administrador pueden gestionar productos y usuarios registrados en el sistema.

## Proposito del sistema

El proposito principal del proyecto es crear una tienda online funcional, organizada y escalable, que sirva como base para un sistema real de ventas de celulares. Ademas, el proyecto funciona como practica academica para aplicar conocimientos de desarrollo web, backend, bases de datos, validacion, verificacion y pruebas automatizadas.

## Alcance actual

El sistema contempla las siguientes areas:

- Pagina principal.
- Catalogo o tienda.
- Registro de usuarios.
- Inicio de sesion.
- Sesion de usuario.
- Carrito de compras.
- Panel administrativo.
- Gestion de productos.
- Gestion de usuarios.
- Base de datos MySQL.
- Pruebas automatizadas con Playwright.

## Usuarios principales

### Usuario cliente

Es la persona que visita la tienda, consulta productos, inicia sesion y utiliza el carrito de compras.

### Usuario administrador

Es la persona encargada de gestionar la informacion interna del sistema, principalmente productos y usuarios.

## Objetivo general

Desarrollar una plataforma web de comercio electronico para la venta de celulares, que permita a los usuarios consultar productos y administrar su carrito, y que permita a los administradores gestionar la informacion principal del sistema.

## Objetivos especificos

- Diseñar una interfaz web clara y funcional.
- Implementar autenticacion de usuarios.
- Permitir la consulta de productos disponibles.
- Permitir la gestion del carrito de compras.
- Implementar un panel administrativo.
- Gestionar productos desde el backend y la base de datos.
- Gestionar usuarios desde el backend y la base de datos.
- Automatizar pruebas basicas usando Playwright.

## Estado del proyecto

El proyecto se encuentra en desarrollo activo. Todavia pueden cambiar rutas, nombres de archivos, estructura interna, endpoints y funcionalidades. Por eso, esta documentacion debe actualizarse cada vez que se agregue una funcionalidad importante.
